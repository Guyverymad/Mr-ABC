ระบบจัดการข้อมูลการลงทะเบียนเรียนออนไลน์ 🎓

โปรเจกต์นี้พัฒนาด้วย ภาษา C เพื่อจัดการข้อมูลการลงทะเบียนเรียนของนักเรียน ผู้ใช้งานสามารถเพิ่ม, แก้ไข, ลบ, ค้นหา และแสดงข้อมูลทั้งหมดได้ นอกจากนี้ยังสามารถบันทึกและโหลดข้อมูลจากไฟล์ CSV ได้อย่างมีประสิทธิภาพ ยังรองรับการบันทึกและโหลดข้อมูลจากไฟล์ CSV ทำให้ข้อมูลไม่สูญหายเมื่อปิดโปรแกรม เป็นการจำลองการรับข้อมูลขนาดเล็กจำกัดการรับอยู่ที่ 290000 ข้อมูล

ระบบยังมาพร้อม โหมดทดสอบ (Test Mode) ที่มีทั้ง Unit Test และ Integration Test เพื่อรับประกันความถูกต้องของฟังก์ชันหลักและการทำงานต่อเนื่องของโปรแกรม

✨ ฟีเจอร์หลัก

✏️ จัดการข้อมูลนักเรียน: เพิ่ม, แก้ไข, และลบข้อมูล
🔍 ค้นหาข้อมูล: ค้นหานักเรียนจาก "ชื่อ" หรือ "รหัสประจำตัวของผู้เรียน"
📋 การเพิ่มฟังก์ชั่นเช็ค: เพิ่มฟังก์ชั่นในการเช็คในระบบว่ามีการลงืะเบียนซ้ำหรือป่าว
📋 แสดงข้อมูล: แสดงข้อมูลนักเรียนทั้งหมดที่มีอยู่ในระบบ
💾 จัดการไฟล์: บันทึกและโหลดข้อมูลจากไฟล์ CSV โดยอัตโนมัติ
🧪 โหมดทดสอบ: มีเมนูสำหรับรัน Unit Test และ Integration Test ได้จากในโปรแกรม
💻 วิธีคอมไพล์และรันโปรแกรม

โปรแกรมนี้เขียนด้วยภาษา C และสามารถคอมไพล์และรันได้บน Windows, macOS, และ Linux

🧩 ขั้นตอนที่ 1: คอมไพล์โปรแกรม

🔹 บน Windows (ใช้ MinGW หรือ MSYS2)

เปิด Command Prompt หรือ PowerShell
ใช้คำสั่ง cd เพื่อไปยังโฟลเดอร์ที่มีไฟล์ finl.c และ tests.h
พิมพ์คำสั่งเพื่อคอมไพล์:
gcc finl.c -o finl.exe
เมื่อคอมไพล์เสร็จ จะได้ไฟล์โปรแกรมชื่อ finl.exe
🔹 บน macOS / Linux

เปิด Terminal
ใช้คำสั่ง cd เพื่อไปยังโฟลเดอร์ที่มีไฟล์ finl.c และ tests.h
พิมพ์คำสั่งเพื่อคอมไพล์:
gcc finl.c -o finl
เมื่อคอมไพล์เสร็จ จะได้ไฟล์โปรแกรมชื่อ finl
🧩 ขั้นตอนที่: การให้สิทธิ์รันโปรแกรม (เฉพาะ macOS / Linux)

โดยปกติ ไฟล์ที่คอมไพล์บน macOS หรือ Linux จะไม่ได้รับสิทธิ์ในการรันโดยอัตโนมัติเพื่อความปลอดภัย คุณต้องให้สิทธิ์ก่อนรัน (ทำแค่ครั้งแรกครั้งเดียว)

ใน Terminal ที่อยู่ในโฟลเดอร์เดียวกับไฟล์ finl พิมพ์คำสั่งนี้:
chmod +x finl
คำสั่งนี้จะไม่มีข้อความตอบกลับมา ซึ่งถือว่าปกติ
🧩 ขั้นตอนที่ 2: รันโปรแกรม

💠 Windows

.\finl.exe
💠 macOS / Linux

./finl
หลังจากรันคำสั่ง เมนูของโปรแกรมก็จะปรากฏขึ้นมาให้ใช้งานได้ทันที

⚙️ ขั้นตอนที่ 3: วิธีแก้เมื่อภาษาไทยแสดงไม่ถูกต้อง

หากเมื่อรันโปรแกรมแล้วพบว่าภาษาไทยแสดงเป็น “????” หรือตัวอักษรเพี้ยน ให้พิมพ์คำสั่งต่อไปนี้ใน Terminal/CMD ก่อนรันโปรแกรม

🪟 Windows

chcp 65001
🍎 macOS / Linux

export LANG=th_TH.UTF-8
export LC_ALL=th_TH.UTF-8
